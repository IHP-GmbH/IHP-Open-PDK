# Standard Cell Schematics

## Overview

This directory contains tool-specific schematic files for the
`sg13g2_stdcell_hv` (thick-oxide, 3.3 V) library.

## Directory Layout

- `qucs-s/`: Qucs-S schematic files
- `xschem/`: Xschem schematic files

## Provenance

The Qucs-S schematics are a device-level retarget of the thin-oxide
`sg13g2_stdcell` schematics: same topology, same nets, same wiring, with the
devices changed to `sg13_hv_nmos` / `sg13_hv_pmos` and resized. Sizes are
taken from the shipped SPICE netlist rather than computed, because the
transform is not a single ratio -- gate length goes 130 nm to 450 nm in the
common case, but 180 nm is clamped to 450 nm, 250 nm becomes 625 nm, and the
deliberately long devices (500 nm, 700 nm, 1 um) are left alone.

`sg13g2_hv_tiehi` and `sg13g2_hv_tielo` are the two exceptions. The
thick-oxide tie cells are a tied-input `inv_1`, not the thin-oxide
four-transistor chain, so they are composed from this library's own `inv_1`
rather than retargeted.

Generated by `work/gen_qucs.py` and gated by `work/verify_qucs.py`, which
checks that the retargeted schematics differ from their thin-oxide originals
only in device size and title-block fields, that every device size matches
the shipped SPICE netlist, and that the two composed tie cells match it
terminal by terminal.
